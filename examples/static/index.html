🚀 欢迎使用 zhttpd

这是一个使用 Zig 语言构建的高性能、可扩展的 HTTP Web 服务器。

✨ 特性

静态文件服务 - 支持 HTML, CSS, JavaScript, 图片等静态资源
Lua 动态处理 - 使用 Lua 脚本处理动态内容和 API 请求
GraphQL API - 内置 GraphQL 支持，提供灵活的 API 查询能力
安全加固 - 默认启用 HTTP 安全头部，包括 CSP、HSTS、X-Frame-Options 等
配置灵活 - 支持 JSON 和 YAML 配置文件
